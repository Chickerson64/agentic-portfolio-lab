# Design Principles

1. If normal code can do something reliably, do not use AI.
2. Every AI decision must be explainable.
3. Important investment claims must point to evidence.
4. Every manager must explain why its decision is better than simply buying SPY.
5. The system is an investment committee, not an oracle.
6. Long-term reasoning matters more than short-term prediction.
7. Paper trading comes before brokerage paper trading.
8. Human approval comes before real-money execution.
9. Build abstractions only after a real need appears.
10. Keep the system understandable to a computer-science student learning the architecture.
